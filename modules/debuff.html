Module debuff

These functions help in retrieving information about debuffs.

Debuff functions are the profile API table `debuff` (br.api.profile.debuff); profiles use it by name. `spell` in the function represent the name in the debuffs list (Spec, Shared Class, Shared Global Lists) defined in Expansions// (Global.lua, /Class.lua, /.lua)
