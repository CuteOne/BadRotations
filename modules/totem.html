Module totem

Totem handling functions for BadRotations.

Totem functions are the profile API table `totem` (br.api.profile.totem); profiles use it by name.

This module provides a hierarchical API for totem checks: - totem.active(candidate) -> checks if any totem matching candidate is active - totem.fire.active() -> checks if any fire totem is active in slot 1 - totem.fire.searingTotem.active() -> checks if searing totem specifically is active

Slot indices: 1 = Fire, 2 = Earth, 3 = Water, 4 = Air.

active (candidate)
Returns true if the specified totem is currently active in any slot. Candidate can be a spell key, spell ID, or localized name.

Parameters:

  • candidate string or number

Returns:

    boolean
anyLeftBehind ([yards=30])
True when any of your totems is up but you're yards or more away from it (left behind; one that can't be located counts as near): time for Totemic Call.

Parameters:

  • yards number (default 30)

Returns:

    boolean
destroy (slot)
Destroys your totem in a slot, as right-clicking its icon does, on clients where a player can (Wrath on; not Classic, TBC or Forever). True when it was asked; false otherwise, with no totem there, or one asked under a second ago.

Parameters:

  • slot number Totem slot (1-4), e.g. totem.fire.slot

Returns:

    boolean
distance (slotOrCandidate)
Returns distance from player to the active totem in a slot. Returns 0 if no totem is active or the object can't be located (check active() first).

Parameters:

  • slotOrCandidate number or string Totem slot (1-4) or totem spell key/id/name

Returns:

    number
