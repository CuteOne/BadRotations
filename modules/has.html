Module has

These functions help in retrieving information if you have an item or not.

Has functions are the profile API table `has` (br.api.profile.has); profiles use it by name. For item has, `item` in the function represent the name in the items list defined in System/List/Items.lua

item (itemID)
Checks if the specified `itemID` is in your bags or not. Note: `item` here is literally item, you pass the itemID to specify the item

Parameters:

  • itemID number The ID of the item to check for.

Returns:

    boolean
has.stats.dps (itemSlot, desiredStat)
Checks if an inventory item has any of chosen DPS stats.

Parameters:

  • itemSlot number The slot number in the player's inventory where the item is located.
  • desiredStat string A string representing the desired stat to check. It can be one of: 'agility', 'strength', 'intellect', 'crit', 'haste', 'mastery', 'versatility', or 'anyDps'. 'anyDps' checks for any DPS-related stat. If `desiredStat` is not recognized, it defaults to 'anyDps'.

Returns:

    boolean True if the item has the chosen DPS stat, False otherwise.
