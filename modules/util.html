Module util

Small helpers a profile needs that aren't about units, spells or the screen: the game clock, named timers and rounding.

Util functions are the profile API table `util` (br.api.profile.util); profiles use it by name.

timer (timerName, interval)
True the first time, then again each time the interval has passed since it was last true

Parameters:

  • timerName string - The name of the timer check, should be unique.
  • interval number - The length of time to wait until true, in seconds.

Returns:

    boolean - Returns true if the interval has passed
