Module glyph

Glyph handling functions for BadRotations.

Glyph functions are the profile API table `glyph` (br.api.profile.glyph); profiles use it by name.

NOTE: On modern retail clients the classic glyph socket API may not exist; in that case glyph checks return false.

Functions

available () Returns whether glyph API is available on this client.
has (glyphSpellId) Returns true if the given glyph spellId is socketed.
socketCount () Returns how many glyph sockets we can scan.
glyph. () Returns true if this glyph is NOT socketed.
glyph. () Returns true if this glyph is socketed.
glyph. () Returns true if this glyph is socketed (glyph..enabled).
glyph. () Returns the glyph spellId.
