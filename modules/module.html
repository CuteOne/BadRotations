Module module

These functions helpful functions for commonly used features in all profiles.

Module functions are the profile API table `module` (br.api.profile.module); profiles use it by name. Additionally module functions also have custom options you can add to your Profile Options by calling the function in the Profile Options and passing the section param.

RacialStun ()
War Stomp just before a cast-time heal on yourself, so the heal lands while what's hitting you is stunned (no pushback). Tauren only; needs the Racial module's "Use Racial" ticked and an enemy within 8 yd attacking you. A profile calls it right before casting the heal; it doesn't count as the profile handling racials.

Returns:

    boolean True when War Stomp was cast

Usage:

    if hpLow and module.RacialStun() then return true end -- then the heal, next tick
Racial ([section[, thisUnit]])
Racial Module - Uses the player's racial abilities based on the options set in the Profile Options. Uses the race's named racial (e.g. cast.stoneform) when the expansion defines one, otherwise cast.racial. On Classic-era expansions cast.racial only maps damage racials, so the named key matters there. Damage racials (Orc, Troll, and Forever's Night Elf / Gnome) use the "Damage Racial" dropdown.

Parameters:

  • section boolean If set will generate the options for this module in the Profile Options. Otherwise, will run the module. (optional)
  • thisUnit string Unit to use the racial on (Quaking Palm requires it). (optional)
