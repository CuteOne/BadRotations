Module buff

These functions help in retrieving information about buffs.

Buff functions are the profile API table `buff` (br.api.profile.buff); profiles use it by name. `spell` in the function represent the name in the buffs list (Spec, Shared Class, Shared Global Lists) defined in Expansions// (Global.lua, /Class.lua, /.lua)
