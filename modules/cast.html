Module cast

These functions help in casting spells and retrieving information about casts.

Cast functions are the profile API table `cast` (br.api.profile.cast); profiles use it by name. `spell` in the function represent the name in the actions list (Spec, Shared Class, Shared Global Lists) defined in Expansions// (Global.lua, /Class.lua, /.lua)

cast.able.id (spellID, thisUnit, castType, minUnits, effectRng, predict, predictPad, enemies)
Checks if a spell can be cast by its ID based on various parameters.

Parameters:

  • spellID number The ID of the spell to check.
  • thisUnit string The target unit for the spell. Can be standard WoW units, dynamic units, or special parameters.
  • castType string Defines the type of AoE or special cast conditions.
  • minUnits number Minimum number of units needed to be hit by AoE spell.
  • effectRng number The AoE's reach: the radius for aoe/ground/targetAOE, the length for cone/rect.
  • predict boolean or number ground: true to predict enemy movement. cone: its angle in degrees; rect: its full width in yards (from spell data; the cast is refused without it).
  • predictPad boolean Pads the prediction cast time. 'predict' must be true.
  • enemies table A table of enemy units that the spell should be cast on.

Returns:

    boolean

macro (macroText[, associatedSpellID[, lockDuration=0.5]])
Runs the macro text passed to it. Optionally integrates with the cast gate's throttle infrastructure when an associated spell ID is supplied.

Parameters:

  • macroText string The macro text to be run.
  • associatedSpellID integer Spell ID representing the intent of this macro. When passed, the cast gate writes castTimers + castIntentLocks for this spell ID so the next tick's gateDoubleCast / gateCooldownTimer blocks immediate re-fires through the same mechanism createCastFunction uses. Callers that don't pass this argument retain the original unprotected behavior (backward-compatible). (optional)
  • lockDuration number Throttle window in seconds. Defaults to 0.5s (matches the createCastFunction success-path convention). (default 0.5)

Returns:

    boolean Always true.

opener. ()
Casts a spell as one step of an opener: same arguments and result as cast.spell (true when the cast is sent). Write the opener as ordinary priority lines; the steps go in the order they're called in. A step that's done or skipped lets the next line run; the current step casts when it can, and while it waits every cast after it in the rotation is refused, so nothing jumps in (lines above the opener still run); later steps wait their turn. A step is done when the game confirms the cast, and skipped when the spell isn't known, its cooldown won't be up in time, or it can't be cast for about two GCDs. A step whose condition is false is passed over. The opener resets out of combat without a target, or on a new target.

Returns:

    boolean

Usage:

    if not debuff.rake.exists("target") then
    if cast.opener.rake() then ui.debug("Casting Rake [Opener]") return true end
end

cast. (thisUnit, castType, minUnits, effectRng, predict, predictPad, enemies)
Cast a spell based on various parameters. The function name is dynamically generated based on the spell name. For example, for a spell named "thisSpell", the function would be `cast.thisSpell()`.

Parameters:

  • thisUnit string The target unit for the spell. Can be standard WoW units, dynamic units, or special parameters like "best", "playerGround", etc.
  • castType string Defines the type of AoE or special cast conditions.
  • minUnits number Minimum number of units needed to be hit by AoE spell.
  • effectRng number The AoE's reach: the radius for aoe/ground/targetAOE, the length for cone/rect.
  • predict boolean or number ground: true to predict enemy movement. cone: its angle in degrees; rect: its full width in yards (from spell data; the cast is refused without it).
  • predictPad boolean Pads the prediction cast time. 'predict' must be true.
  • enemies table A table of enemy units that the spell should be cast on.

Returns:

    boolean

Usage:

    cast.wrath()                                  -- best target, best rank
cast.demoralizingRoar.aoe(10)                 -- around you, 10 yards (aoe/cone/rect/ground/targetAOE:
cast.swipe.aoe(8, 3)                          --   range, minUnits = 1, unit), pet(unit), dead(unit)
cast.blizzard.ground(8, 3)                    -- on the ground where it covers 3+ enemies
cast.healingTouch.rank(3)("player")           -- rank 3, or the highest known below it
cast.healingWave.forAmount(missing)("player") -- the lowest known rank that heals that much
cast.consecration.rank(1).aoe(8, 3)           -- the forms work at a rank, and on cast.able / cast.opener
