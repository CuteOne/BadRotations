Module power

These functions help in retrieving information about player power.

Power functions are the profile API table `power` (br.api.profile.power); profiles use it by name. powerType is the name of the power passed from the builder which cycles all the collected power from the power list powerIndex is the powerID passed from the builder which cycles all the collected power from the power list

power. (cost[, keep=0])
True when the player can pay cost and still have keep left, counting what earlier casts are promised and the game hasn't charged yet (a bolt queued behind the current cast, Maul waiting on a swing): power.() alone doesn't know those

Parameters:

  • cost number What the spell costs (cast.cost.())
  • keep number How much to keep back (a heal's cost, the mana to shift back into a form) (default 0)

Returns:

    boolean

Usage:

    if power.mana.affordable(cast.cost.lightningBolt(), cast.cost.healingWave()) then

Gets the time in seconds until the specified power is maxed (999 if it doesn't regenerate)

power. ([thisUnit="target"])
Gets the current amount of the specified power. Combo points: yours on thisUnit (default "target"); where they're stored on the unit (Classic-era clients), BR's pick is read on itself, not your target

Parameters:

  • thisUnit Combo points only: the unit they were built on (units.dyn5) (default "target")

Returns:

    number

Usage:

    local comboPoints = power.comboPoints(units.dyn5)
