Module spell

These functions help in retrieving information about spells.

Spell functions are the profile API table `spell` (br.api.profile.spell); profiles use it by name. `k` in the function represent the name in the actions list (Spec, Shared Class, Shared Global Lists) defined in Expansions// (Global.lua, /Class.lua, /.lua)

Functions

spell. () What the spell's current rank heals or hits for: the average BR saw it do (direct, not critical, from 2 casts), else the middle of its tooltip's " to ", else nil.
spell. () Returns the spell's cast time.
spell. () Returns the spell's ID.
spell. ([thisUnit="target"]) For a combo point finisher (Ferocious Bite, Eviscerate, ...): true when it's sure to kill the unit at your current combo points and Energy, from the damage the tooltip lists.
spell. () Checks if the spell is known.
spell. () Returns the spell's max range.
spell. () Returns the spell's min range.
spell. () Returns the spell's name (localized).
spell. () Returns the highest rank of the spell the player knows (0 when it isn't known; 1 on clients without ranks).
spell. () Returns the spell's icon texture.
