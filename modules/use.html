Module use

These functions help in retrieving information if you can use an item or not.

Use functions are the profile API table `use` (br.api.profile.use); profiles use it by name. For item use, `item` in the function represent the name in the items list defined in System/List/Items.lua An item list entry may be a table of ranks: the best one held is used. use.able.() says whether the item is ready. use.() also waits while the player casts or channels, like cast.(); use..whileCasting() (and use.slot.whileCasting(13), ...) uses it anyway, for items the game allows during a cast.
